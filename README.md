# Plugins de DomUP para Claude

**Instalar (Claude Code):**
```
/plugin marketplace add diegodomanico/domup-plugins
/plugin install fabrica-clips-domup@domup
```
**Instalar (app de Claude):** Ajustes → Plugins → Agregar desde repositorio → `diegodomanico/domup-plugins`.

Se actualiza solo: cada mejora de la fábrica de DomUP sale como versión nueva de este repo.

| Plugin | Qué hace |
|---|---|
| `fabrica-clips-domup` | Clips para MercadoLibre con el método de la fábrica DomUP |
